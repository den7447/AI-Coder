🇬🇧 English

Overview

AI-Coder is an autonomous AI-driven coding assistant featuring a lightweight Pygame GUI and seamless integration with local Large Language Models (LLMs) via Ollama. It allows you to plan, generate, refactor, and execute code securely on your machine without relying on external cloud APIs.

Features

Pygame GUI: An interactive, responsive graphical interface built right into Python.

Local LLM Support (Ollama): Run models locally and securely for complete privacy and offline capabilities.

Autonomous Task Management: Plan, write, and refine code blocks directly through the interface.

Cross-Platform & Linux Friendly: Designed to run smoothly on Linux and other desktop environments.

Installation & Setup (Linux)

Clone the repository:

git clone https://github.com/den7447/AI-Coder.git
cd AI-Coder


Install and run Ollama (make sure it's installed and your preferred model like llama3 or codellama is pulled):

ollama pull codellama


Set up Python environment:

python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt


Launch AI-Coder:

python3 main.py
